# ELIO

Lernplattform für die Klasse 7bG (Mittelschule Bayern), mit Maskottchen Elo (früher ELON).

- `index.html`: die ganze App in einer Datei (Dashboard, Stundenplan, Hausaufgaben, Üben mit Lernleitern und Lernspielen, Lerntagebuch, Tafel und Stundenbaukasten für die Lehrkraft).
- Live-Verbindung Tafel ↔ iPads: im Demo-Modus nur im selben Browser. Für echten Unterricht `LIVE_CFG.supabaseUrl` und `LIVE_CFG.supabaseKey` setzen (Supabase-Region Frankfurt).
- Datenschutz: nur Spitzname und Nummer der Klassenliste, Fortschritt bleibt auf dem iPad, keine Rangliste.
